Un simulador de batallas Pokémon basado en texto que revive la esencia de las versiones clásicas. El proyecto se enfoca en la **lógica algorítmica** y el **manejo de estados** mediante la terminal.

## ⚔️ Mecánicas del Juego
- **Encuentros Aleatorios:** Algoritmo de probabilidad para enfrentarse a Pokémon salvajes.
- **Desafío de Gimnasio:** Enfrentamiento directo contra el líder **Brock** para poner a prueba tu equipo.
- **Sistema de Progresión (RPG):** Los Pokémon ganan experiencia (XP) y suben de nivel tras cada victoria.
- **Árbol de Habilidades:** Desbloqueo de nuevos movimientos conforme aumenta el nivel del Pokémon.
- **Gestión de Inventario:** Lógica para el uso de objetos y estados de salud.

## 🛠️ Arquitectura Técnica
- **Control de Flujo:** Implementación de ciclos de juego (Game Loops) y condicionales complejos para las batallas.
- **Estructura de Datos:** Uso de objetos y arreglos para gestionar las estadísticas de los Pokémon (HP, ATK, DEF, XP).
- **Interfaz de Consola:** Manejo de entradas y salidas de texto dinámicas para una experiencia inmersiva sin interfaz gráfica.
- **Lógica de Nivelación:** Fórmulas matemáticas para calcular la ganancia de experiencia y el escalado de poder.

## 💡 Conceptos de Ingeniería Aplicados
Este repositorio demuestra habilidades sólidas en:
- **Abstracción:** Representación de entidades complejas (Pokémon) mediante código limpio.
- **Manejo de Errores:** Validación de comandos de entrada del usuario.
- **Escalabilidad:** Código diseñado para añadir nuevos líderes de gimnasio o Pokémon de forma sencilla.
